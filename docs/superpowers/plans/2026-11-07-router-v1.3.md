# dsh-router v1.3 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task.

**Goal:** 分叉创建 worker（双模式）+ 身份卡协议 + 缓存命中观测，按 v1.3 规格落地。

**Architecture:** 缓存优先=统一组合+宿主 session/fork+切换卡；最小面=agents.create 复刻分叉+worker 组合+模型钉。身份/工具范围在历史内卡片；执行层硬闸不变。观测走 session/event 首 assistant 的 cacheReadTokens。

**Spec:** `docs/superpowers/specs/2026-11-07-router-v1.3-design.md`（取证 `docs/research/r10/r11`）

## Global Constraints（继承前版全部；增量）

- **纪律：每个绿色里程碑立即 commit**（本会话代理曾数次静默中断，小步落盘防全损）。
- 预设/patch 行变动后双核查（check-host-rows + check-subrows）双宿主绿。
- 新工具/路由输出过 lossless 门禁；产物重建随源码提交。
- 实施前必读 r10（fork 面与 agents.create 五步、@deepseek-ai/dsh-session/fork 的 buildForkSeed）与 r11（usage.cacheReadTokens 在 assistant/message.data.usage）。

## Review Focus

1. 模式切换零影响存量：切 workerSpawnMode 不重建/注销既有会话与任务。
2. 切换卡写前意图账：同 taskId 同版本重试沿用同 requestId（防静默丢弃，r9 教训）。
3. 缓存优先下 selectModel 绝不被调用（调用即缓存断裂）；最小面下才钉。
4. fork 来源缺位（来源会话已删/预设未注册 agent-preset/not-found）→ infra 分类进熔断，不换路径硬撞。
5. 身份卡幂等：Router 卡注入对同一会话只发一次（重启/多次派发不重发）。

## Part A：统一组合、身份卡与分叉创建（一个代理，主线 worktree）

### Task A1: workerSpawnMode 配置 + 统一组合引擎

**Files:** Modify `src/host/root-config.ts`（+`workerSpawnMode: 'cache-priority'|'minimal-face'` volatile，默认 cache-priority）、`src/host/prompts/unified.ts`（新建：身份中立 persona 全文，含身份卡协议）、`src/host/presets/{dynamic.ts,lifecycle.ts}`（cache 模式：router/supervisor/worker 类型三预设 plugins 统一为超集组合（persona=unified + 工具超集行 + compaction 组），worker 类型动态定义同构；minimal 模式维持现状）、`cordis.patch.yml`（静态行同步）、tests/{presets-dynamic,bundle,prompt 相关}.spec 扩展。

- [ ] 测试先红：cache 模式下三预设 plugins 逐行相同（工具超集清单断言）、minimal 模式维持现差异；persona 同步看守更新。
- [ ] 双核查绿 → commit `feat(fork): unified composition under cache-priority mode`。

### Task A2: 身份卡与切换卡

**Files:** Create `src/host/prompts/identity-cards.ts`（`routerIdentityCard()`（职责+工具范围）、`switchCard(type, role)` 三件套：类型系统提示词为身份职责 + 本身份工具清单逐一列名（cache 超集下的角色裁剪表）+ 禁用提醒）、Modify `src/host/bridge/sessions.ts`（Router 卡注入：我们的 createRouterSession 成功后 queue 投递一次（requestId=`identity-<sessionId>` 幂等）；picker 自建的 Router 会话由 dedup 收编时补发一次——「已发」标记入 ui-state 防重发）、`src/host/core.ts`（dispatchTask 的投递内容：cache 模式=switchCard+任务书；minimal=现行 workerInstructions+任务书，附简化身份头）。
- [ ] 测试先红（含 Review Focus 5 幂等、切换卡三段齐、工具清单按角色裁剪正确）→ 绿 → commit `feat(fork): identity cards and switch card delivery`。

### Task A3: 分叉创建 worker（双模式）

**Files:** Modify `src/host/bridge/sessions.ts`（创建段替换：cache=`host.forkSession({sessionId: 来源})`（宿主 face 名以 r10 取证为准，缺面→infra 降级）；minimal=五步复刻（新 sessionId + `buildForkSeed` + inheritedEventCount + worker 预设 setup（经 agentPresets resolve/mount 或等价面）+ 创建），后接 attach workspace、rename `类型名 · T-xxx`、**cache 模式不调 selectModel**）；`src/entry.ts`（注入 fork/agents.create face）；tests 扩展（两模式路径、来源缺位 infra、Review Focus 3/4）。
- [ ] 先红后绿 → 双核查 → commit `feat(fork): fork-spawned workers in both modes`。

### Task A4: 提示词与指引

**Files:** prompts/{router,supervisor}.ts + yml 同步：派发通道选择准则（轻→子代理、重/持久→分叉 worker）、cache 模式下类型提示词经切换卡生效的说明；创建类型指引保留。
