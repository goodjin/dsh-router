# dsh-router v1 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 `@goodjin2/dsh-router` v1：Router/主管/工作型 worker 会话任务编排插件（规格见 Spec）。

**Architecture:** 宿主侧 Cordis 服务承载任务账本、调度、文档、记忆、上下文与问答桥；浏览器侧 client 插件承载会话导航标签条、问题浮窗与项目栏入口；Router/worker 都是独立持久会话，由插件维护任务关系；模型上下文靠「活动账本快照（PromptContext）+ 派发后压缩」保持精简。

**Tech Stack:** TypeScript、Cordis（DSH 插件框架）、tsdown（单文件 CJS 工厂产物）、vitest、React（client 侧，走宿主 slots）。

**Spec:** `docs/superpowers/specs/2026-11-07-router-v1-design.md`

## Global Constraints

- 包名 `@goodjin2/dsh-router`；bundle id = 包名；装载三条件见仓库 AGENTS.md（patch 裸包名行、`dsh.client.platform=web`、`dsh.bundle.patch`）。
- 门禁三条：`npm run typecheck` / `npm test` / `npm run build` 全绿；产物 `dist/entry.js`、`lib/client.js` 入库且可复现。
- 浏览器代码不进宿主进程：`.` 入口只指向宿主侧文件。
- 宿主契约以官方文档镜像与宿主 checkout 源码为准（研究笔记在 `/tmp/dsh-router-research/`，定稿后收进 `docs/research/`）。
- 领域核心（账本/状态机/文档）不得 import 宿主专有包——纯 TypeScript + 注入式 IO，保证可测可移植。
- 任务 ID 项目内单调（`T-001` 起）；任务书版本 `task.vN.md` 单调递增、历史版本不可变。
- 所有持久化目录可配置；默认任务文档在 `<项目cwd>/.router/tasks/`、插件状态在 `${DSH_HOME}/router/`。

## Review Focus

- 状态机非法迁移：任何从未定义的迁移必须抛错而不是静默通过（尤其 `completed`/`cancelled` 后的一切写操作）。
- 重复派发/重复完成：同任务同版本的第二次 `complete` 必须幂等返回首次结果，不得产生第二条记录。
- 依赖环：`dependsOn` 出现环时创建/派发必须拒绝并给出环路径。
- 压缩边界：活动账本快照必须覆盖**全部**未结束任务；完成任务从快照消失但归档可查，两者同时成立。
- 旧 worker 迟到提交：`complete` 携带旧 docVersion 必须拒绝；`supplement` 升版后旧版本引用不得再解锁任何东西。

### 客户端↔宿主 API 契约（两侧共同实现，不得偏离）

共享视图类型放 `src/shared/view-contract.ts`（client 与 host 都 import；client 不 import src/host/**）：

```ts
interface TaskCard { taskId: string; title: string; goal: string; status: TaskStatus; role: 'supervisor'|'worker';
  templateId: string; progress?: string; sessionId?: string; waitingQuestions: number; parentId?: string; docVersion: number }
interface QuestionCard { questionId: string; taskId?: string; taskTitle?: string; sessionId: string; sessionTitle?: string;
  questions: AskUserQuestionItem[]; receivedAt: number }
interface RouterSessionInfo { sessionId: string; title: string }
interface WorkerTabInfo { sessionId: string; title: string; taskId?: string; taskStatus?: TaskStatus; running: boolean }
interface WorkerTemplate { templateId: string; name: string; description: string; role: 'supervisor'|'worker' }
interface RouterState { routerSessions: RouterSessionInfo[]; tasks: TaskCard[]; questions: QuestionCard[];
  tabs: WorkerTabInfo[]; templates: WorkerTemplate[] }
```

HTTP 路由（exact，均同源 fetch，JSON；错误 `{ error: string }` + 4xx/5xx）：
- `GET /router/state?workspaceId=` → `RouterState`（tabs 为该 workspace 持久标签序）
- `POST /router/router-session` `{ workspaceId, name? }` → `{ sessionId }`（preset `dsh-router` 建会话 + attach workspace）
- `POST /router/answer` `{ questionId, answers: AskUserQuestionAnswerItem[] }` → `{ ok: true }`；已答 409
- `POST /router/tabs/close` `{ workspaceId, sessionId }` → `{ ok: true }`（只移出标签条，会话与任务不受影响）
