# dsh-router v1.1 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地 v1.1 规格：P0 修复 → 三项先行验证 → worker 类型动态预设体系、设置管理、提示词编辑、派发护栏、浮窗联动、样式，最终通过「数插件」回归验收。

**Architecture:** 沿 v1 双半边结构（宿主服务 `routerCore` + HTTP 路由 + client 工厂）。新增：worker 类型存储与动态预设引擎（运行时注册/撤下）、问答桥预算强制、Router 预设动态化（静态回退）。预设子行配置以宿主自带预设为基准并受校验双轨（离线脚本 + 注册时函数）约束。

**Tech Stack:** 同 v1（TypeScript、Cordis、tsdown、vitest、React via slots）。

**Spec:** `docs/superpowers/specs/2026-11-07-router-v1.1-design.md`（本计划从它出发生成）

## Global Constraints（继承 v1 计划全部约束，增量如下）

- 预设/声明行改动后：`node /Users/good/github/dsh-plugins/scripts/check-host-rows.mjs dsh-router` 双宿主绿 **且** 本仓 `node scripts/check-subrows.mjs` 双宿主绿。
- 动态注册的每个预设子行必须过 `validateRowSpec`（A2 产出，脚本与运行时共用）。
- 新增/改动的模型工具输出值一律过 lossless-JSON 门禁测试（A3 helper）。
- `lib/client.js` 仍为单文件 CJS 工厂；`exports["./client"]` 形状不变；客户端不 import `src/host/**`（共享类型只经 `src/shared/view-contract.ts`）。
- 全部功能开发在 worktree `router-v1.1`；每任务 TDD + commit；产物重建随源码提交。

## Review Focus（对应测试落位）

1. **动态注册失败不炸装载**：内置「通用 worker」与静态 Router 回退在任何注册异常下仍可用（C1 测试模拟 register 抛错）。
2. **去重跳转竞态**：连续两次快速新建只跳转一次；归档失败时不丢「已有 Router」事实（C4）。
3. **提问预算误伤**：预算按任务计；被拒提问的自动回答必须指明出路（report_blocker）（C6）。
4. **complete 段唯一性**：动态提示词 section 与宿主段冲突时报错可回退（C5）。
5. **空壳清理不删档**：清理只影响标签条与活动快照，账本文件记录保留（C6）。

**Interfaces:**
- `interface WorkerTypeRecord { templateId: string; name: string; description: string; role: 'worker'|'supervisor'; models: string[]; systemPrompt: string; skills: string[]; enabled: boolean; origin: 'builtin'|'user'|'router'; createdAt: number; updatedAt: number }`
